## 🎯 Project Overview

**KafKart** is a full-featured, scalable e-commerce platform demonstrating modern software architecture principles. Built with Next.js 16 for the frontend and a Turborepo-managed microservices backend, it showcases enterprise-grade patterns including event-driven architecture with Kafka, payment processing with Stripe, and role-based access control.

### Project Goals

- **Scalability**: Microservices architecture allowing independent service scaling
- **Modern Stack**: Leveraging latest React 19, Next.js 16, and cutting-edge tools
- **Real-world Patterns**: Implementing production-ready e-commerce workflows
- **Developer Experience**: Monorepo structure with shared packages and consistent patterns
- **Performance**: Optimized rendering with Turbopack and efficient state management

### Use Cases

- Full-featured online store with product catalog
- Multi-role admin dashboard for business operations
- Event-driven order processing and payment workflows
- Scalable microservices template for other projects

### Configuration Choices

**Next.js Setup Configuration:**
- ✅ TypeScript: No (JavaScript ES6+ with JSDoc)
- ✅ ESLint: Disabled (configured later if needed)
- ✅ Tailwind CSS: Yes
- ✅ `src/` directory: Yes (better organization)
- ✅ App Router: Yes (recommended modern approach)
- ✅ Turbopack: Yes (faster than Webpack)
- ✅ Import alias: `@/*` (default)

**Rationale:**
- **JavaScript over TypeScript**: Faster prototyping, less boilerplate for MVP
- **No linter initially**: Focus on functionality first, can add later
- **App Router**: Future-proof with Server Components and improved performance
- **Turbopack**: Significantly faster development builds

### Service Communication Flow

**Example: Order Creation Flow**

1. **Customer** submits order via storefront
2. **Next.js API** receives request
3. **Order Service** creates order in database
4. **Kafka** publishes `order.created` event
5. **Payment Service** consumes event, processes payment
6. **Payment Service** publishes `payment.processed` event
7. **Order Service** updates order status
8. **Email Service** consumes event, sends confirmation email
9. **Frontend** receives success response

## 🚀 Setup & Installation

### Step 01(Prerequisites): Verify Node.js Environment

Ensure you have the following installed on your system:

```bash
# Check Node.js (v18+ recommended)
node -v  # Should output v18.x.x or higher

# Check npm
npm -v   # Should output 9.x.x or higher

# Check npx (usually comes with npm)
npx -v
```

### Step 02: Initialize Project

Install the latest Next.js on your system

**Required Software:**
- Node.js: v18.0.0 or higher
- npm: v9.0.0 or higher
- Git: v2.30.0 or higher
- PostgreSQL: v14+ (for development)
- MongoDB: v6+ (for development)
- Kafka: Local or cloud instance

```bash

npx create-next-app@latest kafkart
```

- Tailwind CSS: **Yes**
